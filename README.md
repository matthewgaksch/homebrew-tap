# Gaksch Tap

## How do I install these formulae?

`brew install gaksch/tap/<formula>`

Or `brew tap gaksch/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gaksch/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
